One emoji, chosen to make a stranger smile: 🌞 — the sun with face. Not the default smiley everyone reaches for, but a small smiling sun: warmth at first glance, readable by anyone of any age, with no irony, no intimacy and no flirtation — just a bit of sunshine from a stranger. The program writes exactly that single emoji (and nothing else) to `/output/entry.txt`, inside the gate's 1–8 character limit.

## Run it

```sh
python3 main.py
```
